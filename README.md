# دنیای روپولی — MONOPOLY WORLD 3D

> 🎮 **دانلود سریع:** آخرین APK (نسخه‌ی امضاشده) از صفحه‌ی [Releases](../../releases/latest) این مخزن قابل دریافت است — فایل `MonopolyWorld3D-v1.1.0-release.apk` را نصب کنید.

بازی کامل خرید و فروش املاک به سبک کلاسیک روپولی، با تم شهر تهران، گرافیک سه‌بعدی سبک و رابط کاربری تمام‌فارسی برای گوشی‌های اندرویدی. کاملاً آفلاین، بدون هیچ دسترسی اینترنتی.

- **نام بسته:** `com.monopoly.world3d`
- **نسخه:** ۱٫۱٫۰ — **minSdk:** ۲۴ (اندروید ۷ به بالا) — **targetSdk:** ۳۴
- **حجم APK:** حدود ۲٫۵ مگابایت (خیلی کمتر از سقف ۳۰۰ مگابایت)
- **فناوری:** Kotlin + OpenGL ES 2.0 (بدون Unity/Godot، بدون هیچ کتابخانه‌ی خارجی)

## 📋 تاریخچه نسخه‌ها

### نسخه ۱٫۱٫۰ (versionCode 2) — رفع کرش شروع بازی و پایداری کامل

- **رفع کرش اصلی (بسته‌شدن هنگام شروع بازی):** `IndexOutOfBoundsException` در کشیدن کارت شانس/اتفاقات — دسته‌ی کارت‌ها پیش از اولین فرود روی خانه‌ی کارت خالی بود و `shuffleDecks` لیست را بازسازی می‌کرد؛ اکنون دسته‌ها «در جا» پر می‌شوند و `Engine.startGame()` همیشه در آغاز بازی فراخوانی می‌شود.
- **رفع باگ اقتصاد:** موجودی آغازین بازیکنان از صفر به ۱٬۵۰۰٬۰۰۰ تومان اصلاح شد (فراخوانی نشدن `startGame`).
- **رفع توقف AI در حراج:** پیشنهادِ کمتر از حداقل دیگر ثبت نمی‌شود؛ AI با موجودی ناکافی انصراف می‌دهد.
- **گارد ضدمکث AI** در صفحه بازی (۴۰ گام بدون تغییر وضعیت → بستن اجباری نوبت) و گارد خرید ملک نامعتبر.
- **بازیابی حراج نیمه‌کاره** برای همه‌ی انواع بارگذاری (خودکار و اسلت‌های دستی).
- **سخت‌سازی رندر:** زنجیره‌ی کامل fallback در انتخاب‌گر EGL، محافظت خطاهای شیدر/بافت/ترسیم در رشته‌ی GL.
- **ثبت‌کننده‌ی سراسری خطا:** هر کرش احتمالی با stack trace در `crash_log.txt` ذخیره می‌شود.
- حذف دکمه‌ی تکراری منو؛ ۷ تست رگرسیون جدید — **۸۵ تست پاس**.

## ۱) نصب سریع با APK آماده

دو فایل APK آماده در پوشه‌ی [`apk/`](apk/) این مخزن (و در صفحه‌ی [Releases](../../releases)) موجود است:

| فایل | کاربرد |
| --- | --- |
| `MonopolyWorld3D-v1.1.0-release.apk` | نسخه‌ی نهایی امضاشده — برای بازی و نصب روی گوشی |
| `MonopolyWorld3D-v1.1.0-debug.apk` | نسخه‌ی دیباگ برای توسعه‌دهندگان |

**مراحل نصب روی گوشی:**
1. فایل `MonopolyWorld3D-v1.1.0-release.apk` را به گوشی منتقل کنید (کابل، بلوتوث یا پیام‌رسان).
2. روی فایل بزنید؛ اگر پیام «نصب از منابع ناشناس» آمد، اجازه‌ی نصب را به مرورگر/فایل‌منیجر بدهید.
3. «نصب» را بزنید. بازی در فهرست برنامه‌ها با نام **دنیای روپولی** ظاهر می‌شود.
4. بازی کاملاً آفلاین است؛ هیچ اینترنتی لازم نیست.

> نسخه‌ی Release با یک کلید self-signed امضا شده است. برای انتشار در کافه‌بازار یا گوگل‌پلی، کلید خودتان را بسازید (بخش ۴).

## ۲) ساخت پروژه در Android Studio

1. **Android Studio Hedgehog (2023.1.1) یا جدیدتر** را نصب کنید (به همراه SDK Platform 34 که خود Studio پیشنهاد می‌دهد).
2. از منوی `File → Open` پوشه‌ی `MonopolyWorld3D` (همین پوشه) را باز کنید.
3. صبر کنید تا Gradle Sync تمام شود (بار اول چند دقیقه طول می‌کشد).
4. از منوی `Build → Build Bundle(s) / APK(s) → Build APK(s)` خروجی بگیرید؛ یا مستقیم دکمه‌ی سبز **Run ▶** را با گوشی متصل/شبیه‌ساز بزنید.

### ساخت از خط فرمان

```bash
# لینوکس/مک
./gradlew assembleDebug          # خروجی: app/build/outputs/apk/debug/app-debug.apk
./gradlew assembleRelease        # خروجی: app/build/outputs/apk/release/app-release.apk
./gradlew testDebugUnitTest      # اجرای ۷۸ تست خودکار موتور بازی
```

در ویندوز به‌جای `./gradlew` از `gradlew.bat` استفاده کنید.
اگر `ANDROID_HOME` تنظیم نیست، فایل `local.properties` بسازید:

```properties
sdk.dir=C\:\\Users\\YOUR-NAME\\AppData\\Local\\Android\\Sdk
```

## ۳) امضای نسخه‌ی Release

کلید فعلی در `app/release-key.keystore` است (رمز store و key هر دو: `monopoly2024`، نام مستعار: `monopolyworld3d`). برای انتشار عمومی، کلید شخصی بسازید و مقادیر در `app/build.gradle.kts` (بخش `signingConfigs`) را عوض کنید:

```bash
keytool -genkeypair -v -keystore my-release.keystore -alias myalias \
  -keyalg RSA -keysize 2048 -validity 10000
```

## ۷) عیب‌یابی

- **Gradle Sync شکست خورد:** مطمئن شوید SDK 34 نصب است؛ `local.properties` را بررسی کنید.
- **نصب APK متوقف شد:** نسخه‌ی اندروید گوشی باید ۷٫۰ به بالا باشد؛ «نصب از منابع ناشناس» را فعال کنید.
- **کند بودن گرافیک:** در «تنظیمات → کیفیت گرافیک» گزینه‌ی «کم» را انتخاب و بازی را دوباره باز کنید.
- **بازگردانی بازی خراب:** اگر فایل اسلات خراب شود، بازی به‌طور خودکار از نسخه‌ی پشتیبان (`.bak`) بازیابی می‌کند.
